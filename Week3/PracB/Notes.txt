Topic 3 Prac A Reflection

Inheritance reduces duplicated code because common properties and methods can be placed in the BankAccount base class. SavingsAccount and CheckingAccount can then reuse that functionality instead of implementing it again.

SavingsAccount is responsible for storing an interest rate and applying interest to the balance.

CheckingAccount is responsible for storing a transaction fee and deducting the fee whenever a withdrawal is made.

The DisplayAccountInfo method is virtual in the base class and overridden by the derived classes so that each account type can display its own additional information.
